Ondo 是一款优雅的 IPTV 播放器，适用于 iPhone、iPad 和 Mac。添加服务商提供的 M3U 播放列表或 Xtream Codes 登录信息，其中的电影、剧集和频道就会变成一个简洁、快速、无广告的媒体库。

电影与剧集
• 海报墙、分类、排序（上映日期、评分、名称……），以及可按上映年份筛选的即时搜索
• 丰富详情：剧情简介、演员阵容、评分、预告片、季与集
• 点按演员或导演，即可查看他们在你播放列表中的其他电影和剧集
• 电影页面显示奖项与电影节入选情况（戛纳、奥斯卡、柏林、威尼斯、凯撒奖……），并可查看播放列表中的获奖电影
• 继续观看：从上次停下的位置准确续播，下一集自动开始
• “我的片单”把电影、剧集和频道集中在一处，还可用合集按你的方式分组

省心好用的播放器
• 双引擎：Apple 播放器（HDR10、杜比视界、杜比全景声、画中画、AirPlay），iPhone 和 iPad 上能解码时也可播放 MKV 电影；其余内容（MKV、AVI、TS）由基于 VLC 的引擎播放
• 音轨与字幕、SRT/VTT 字幕文件、画面比例、播放速度、睡眠定时器、控制锁定
• 在播放器中在线搜索字幕：OpenSubtitles、SubDL 和 SubSource（使用你自己的密钥），剧集还可用无需密钥的 Addic7ed
• 清晰的错误提示，告诉你问题出在服务商、网络还是应用

在电视上观看
• 从 iPhone、iPad 和 Mac 使用 AirPlay：画面和声音都会投到电视
• 从 iPhone 和 iPad 使用 Chromecast

在 Mac 上
• 每个视频一个窗口，支持全屏（按钮、F 键或双击）、键盘快捷键和“播放”菜单

直播
• 频道、节目指南和回看（需服务商支持）：从头重播当前节目、观看已播出的节目、暂停直播
• 频道可加入“我的片单”，并可设置节目提醒
• 在 iPad 和 Mac 上最多同时多画面观看 4 个频道

适合全家人
• 每个用户档案拥有独立的“我的片单”和观看记录，可选 PIN 码和儿童档案
• 家长控制：用 PIN 码锁定成人分类

来源
• M3U / M3U8 播放列表（链接或文件）、Xtream Codes、XSPF 和 JSON 播放列表
• 多个播放列表、自动刷新、备份

语言
• 英语、法语、西班牙语、葡萄牙语、简体中文、阿拉伯语和印地语

隐私
• 无需账号，无广告，也没有自己的数据分析：你的播放列表和观看记录都保存在你的设备上。开启“在此网络同步”后，它们也会传送到同一网络中的其他 Ondo 设备，绝不经过互联网。
